# SMS Hindi Shayari

Modern, SEO Friendly, Multi-Language Shayari Website with AI Image Generator.

## Features

- Modern Responsive Design
- Admin Dashboard
- Multi Language Support
- AI Shayari Image Generator
- GitHub Background Images
- Image Download
- Text Copy
- Category Management
- Comments + Admin Reply
- SEO Friendly URLs
- Dynamic Sitemap
- Robots.txt
- Google AdSense Ready
- Analytics Dashboard
- PWA Support
- Dark / Light Mode

# Installation

## Clone Repository

```bash
git clone https://github.com/USERNAME/sms-hindi-shayari.git
```

## Install Packages

```bash
npm install
```

## Create Environment File

```bash
cp .env.example .env
```

## Start Development Server

```bash
npm run dev
```

## Production

```bash
npm start
```
