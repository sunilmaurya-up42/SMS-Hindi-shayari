# Uploads Directory

This directory stores uploaded files used by SMS Hindi Shayari.

## Structure

- shayari/     -> Shayari images
- profile/     -> User profile images
- background/  -> Background images
- temp/        -> Temporary uploaded files

Notes:

- Do not delete these folders.
- `.gitkeep` files are used to keep empty folders in Git.
- Temporary files should be cleaned periodically by the application.
